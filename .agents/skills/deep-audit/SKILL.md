description: |
  对本仓库执行深度一致性审计。适用于阶段完成后、Codex 能力明显变化后，
  或准备整理版本前的全局复核。
argument-hint: "[--no-fix]"
allowed-tools: Read Write Edit Bash Grep Glob
---

对本仓库执行深度审计，并输出结构化报告。

工作流：

1. 读取 `AGENTS.md`、roadmap、活跃 specs 和架构说明。
2. 检查仓库当前状态，识别当前里程碑。
3. 审核以下漂移：
   - 主文档与提示词之间
   - 主文档与 starter 模板之间
   - 研究结论与用户可见结论之间
   - 项目 Rules、命令约束与实际仓库状态之间
4. 如果没有传 `--no-fix`，可直接修复小而确定的文档漂移。
5. 如果这次审计范围较大，就在 `docs/reports/` 下落一份报告；否则内联总结。

输出格式：

- 检查范围
- 未运行的检查
- 严重发现
- 中等级发现
- 低优先级发现
- 已修复项
- 剩余风险
- 下一步建议

规则：

- 不要以“审计”为名做大规模改写。
- 除非用户明确要求，只修高置信度的小漂移。
