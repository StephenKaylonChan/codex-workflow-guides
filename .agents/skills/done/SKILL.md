---
name: done
description: |
  在一个文档或模板切片完成后做收尾检查，并同步项目状态。
  适用于准备提交或准备交接前的闭环动作。
argument-hint: "[本次完成了什么]"
allowed-tools: Read Write Edit Bash Glob Grep
---

在 commit 前为当前切片做收尾。

工作流：

1. 识别刚完成的切片。
2. 总结验证状态：
   - 跑了什么检查
   - 没跑什么检查
   - 做了哪些术语或一致性复核
   - 当前剩余风险
3. 如果需要，更新 roadmap 或 spec 状态。
4. 如果后续还有工作未结束，更新 session-notes。
5. 输出最终收尾摘要：
   - 完成状态
   - 验证状态
   - 审查状态
   - 已同步文档
   - 剩余风险
   - 下一步建议

输出格式：

- 完成状态
- 验证状态
- 审查状态
- 已同步文档
- 剩余风险
- 下一步建议

规则：

- 如果验证还不清楚，不要标记为 done。
- 只要本次切片改变了项目状态，就不要跳过 roadmap 或 spec 更新。
- 如果没做 review，要明确说没做，不能含糊带过。
