---
name: handoff
description: |
  在离开、切换主题或清空上下文前，保存结构化会话状态。
  适用于中途暂停、结束长会话或准备换一个任务时。
allowed-tools: Read Write Edit Bash Grep Glob
---

生成一份结构化交接，让下一次会话能快速接上。

工作流：

1. 读取 `AGENTS.md`、当前状态和最近变化。
2. 更新 `.agents/session-notes.md`，写入：
   - 已完成
   - 进行中
   - 关键决策
   - 已改动文件
   - 精确的下一步
   - 已知风险或阻塞
3. 如果 roadmap 或 spec 状态已经明确变化，就先同步。
4. 最后总结下一次会话应该如何开始。

输出格式：

- 已完成
- 进行中
- 关键决策
- 已改动文件
- 精确的下一步
- 已知风险或阻塞

规则：

- 不能编造文件或检查里不存在的进度。
- 除非用户或项目明确要求，不要自动 commit。
- 优先写可立即执行的下一步，不要写长篇叙述。
- 下一步必须具体到新会话一进来就能开工。
