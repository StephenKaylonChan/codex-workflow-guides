---
name: task
description: |
  处理一个边界清楚、能在当前会话内闭环的小任务。
  适用于小需求、小 Bug、微调、局部文档修正或小范围模板更新。
argument-hint: "[本次要做什么]"
allowed-tools: Read Write Edit Bash Glob Grep
---

在不额外膨胀流程的前提下完成一个小任务。

工作流：

1. 先判断这是不是小任务：
   - 目标明确
   - 影响范围有限
   - 当前会话内可验证
2. 如果任务已经跨多个决策点、多个提交或明显会扩散，停止直接实施，改为建议先用 `$spec`。
3. 对小任务执行最小闭环：
   - 探索相关文件
   - 实施改动
   - 跑与范围匹配的验证
   - 明确是否需要同步 roadmap、spec 或 session-notes
4. 输出：
   - 任务摘要
   - 已做改动
   - 验证状态
   - 是否需要后续状态同步
   - 剩余风险
   - 下一步

输出格式：

- 任务摘要
- 已做改动
- 验证状态
- 状态同步
- 剩余风险
- 下一步

规则：

- 不能把明显超过小任务边界的改动伪装成 task。
- 没跑过的检查不能写成已验证。
- 如果这次小任务改变了路线图状态，也要同步状态，不因为是小任务就跳过。
